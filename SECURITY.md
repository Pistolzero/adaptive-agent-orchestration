# Security policy

This repository contains instructions and optional role configurations. It does not require secrets or an API key, and it cannot enforce an actual sandbox. Never enable full access solely to make a Skill work.

**Do not report secrets publicly.** For a security concern, open an issue containing only non-sensitive reproduction details, or use GitHub's private vulnerability reporting if enabled. Do not upload real account status screenshots with identifying fields, credentials, raw logs, or user project data.

Known risks include prompt injection through external sources, misuse of broad parent permissions by spawned agents, false quota assumptions, double-editing mutable files and unverified success claims. This Skill documents mitigations but cannot guarantee them.
